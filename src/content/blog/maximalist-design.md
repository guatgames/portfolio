# Maximalist Design in Web Development

Minimalism has dominated web design for a decade. But maximalism is making a comeback — and done right, it's anything but messy.

## What Maximalism Means

Maximalism isn't clutter. It's **richness** — layered gradients, bold typography, unexpected color combinations, and motion with personality.

### Principles to Follow

1. **Hierarchy first** — Even dense layouts need a clear focal point
2. **Consistent motion language** — Every animation should feel intentional
3. **Color with purpose** — Bold palettes still need contrast and accessibility
4. **Performance guardrails** — Animate efficiently; respect `prefers-reduced-motion`

### In Practice

This very portfolio uses floating mesh gradients, text scramble effects, staggered reveals, and a vivid accent palette — all while scoring 100/100 on Lighthouse performance.
