# Spotinder

## Overview

Select your favorite singers and get music recommendations built from the artists and songs you already like.

The interface is a normal, scrollable web page — no window chrome, no fake phone frame — dressed in an Apple Liquid Glass aesthetic over Deezer's dark-mode palette, with a floating glass header and bottom navigation. Swiping is the whole interaction: like a track, keep going, and the next recommendation is already on its way.

## Architecture

Built with modular and component-based architecture: a React, TailwindCSS and TypeScript front end over a Node.js and Express backend.

Deezer is never called straight from the browser. Every request goes through a Netlify Edge Function proxy, so the API credentials stay server-side and out of the client bundle.
