# OpenPay CLI

## Overview

A command-line tool that brings payment management to the terminal with an exceptional developer experience.

## Features

- Unified interface across multiple payment providers
- Interactive prompts with autocomplete
- Rich terminal output with color and tables
- Comprehensive test suite with Vitest
