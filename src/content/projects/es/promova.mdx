# Promova

## Resumen

Envía una imagen y obtén un anuncio para tus redes sociales.

El flujo es deliberadamente corto. Sube una foto de tu producto y Promova deduce la colorimetría de esa imagen — el color dominante, el color de fondo y una paleta completa — y luego traslada esos colores al prompt, de modo que el creativo generado se mantenga fiel a la marca en lugar de inventar su propia estética.

## Cómo funciona

1. **Sube** una foto de tu producto.
2. **Analiza** — Promova extrae el color dominante, el color de fondo y genera una paleta acorde.
3. **Construye el prompt** — el análisis de color se combina con tu identidad de marca en un prompt publicitario que puedes ajustar.
4. **Genera** — los modelos de IA convierten ese prompt en creativos publicitarios, medidos mediante un sistema de créditos mensuales.

## Arquitectura

Construido con arquitectura modular y de componentes: un frontend en React, TailwindCSS y TypeScript sobre una API en Node.js y Express, con Prisma gestionando la capa de datos sobre PostgreSQL y JWT cubriendo la autenticación. La generación se apoya en los modelos de Pollinations, y el saldo mensual de créditos es lo que mantiene acotado el uso.
