# Portfolio 2026

## Overview

The portfolio is more than just a collection of work — it's a living example of what's possible with modern web development.

## Key Features

- **Bilingual i18n** — Client-side language switching between English and Spanish with persistent state
- **Maximalist motion design** — Scroll-triggered animations, text scramble effects, parallax, magnetic buttons
- **Dark/Light theme** — Theme system with localStorage persistence and system preference detection
- **Content collections** — Type-safe MDX content for projects, blog posts, and technologies
- **Netlify Forms** — Zero-backend contact form with full validation

## Technical Highlights

Using Astro's island architecture, only the interactive parts are hydrated, keeping the site incredibly fast while still delivering rich interactivity.
